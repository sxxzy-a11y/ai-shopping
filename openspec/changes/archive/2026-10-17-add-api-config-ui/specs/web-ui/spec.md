## ADDED Requirements

### Requirement: 项目说明页的 API 配置区块

项目说明页 SHALL 提供 API 配置区块，展示两组服务：

- **对话模型**：服务商、端点、模型名、密钥脱敏状态
- **向量化**：服务商、端点、模型名、维度、密钥脱敏状态

管理员 SHALL 能够编辑端点、模型与密钥（密钥为密码输入框，留空表示不修改），并 SHALL 能够对两组服务分别执行连接测试。保存成功后 SHALL 立即生效并刷新页面状态。

非管理员 SHALL 只能查看当前配置状态，看不到编辑控件与保存按钮。

#### Scenario: 管理员保存配置后状态刷新

- **WHEN** 管理员修改对话模型名称并保存
- **THEN** 页面显示新的模型名，后续请求使用新值

#### Scenario: 普通用户只读

- **WHEN** 普通用户打开项目说明页
- **THEN** 能看到当前模式、模型与端点，但看不到密钥输入框与保存按钮

#### Scenario: 连接测试给出明确结果

- **WHEN** 管理员点击某组服务的「测试连接」
- **THEN** 页面显示成功或失败原因；向量测试还会校验返回维度

#### Scenario: 恢复环境变量配置

- **WHEN** 管理员点击「恢复为环境变量配置」
- **THEN** 本机覆盖配置被清除，页面显示回退后的配置
