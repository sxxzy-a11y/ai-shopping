## Why

现在更换 DeepSeek（对话）或阿里云百炼（向量化）的 API 配置，必须编辑 `.env` 并重启应用。演示与调试时这很不方便：改了模型或换了个密钥，要回到终端、改文件、重启，才能验证。

用户要求把两套 API 的配置与切换做进「项目说明」页。

## What Changes

- **项目说明页新增「API 配置」区块**：
  - 展示两组配置：**对话模型（DeepSeek）**、**向量化（阿里云百炼）**
  - 每组显示当前生效的服务商、端点、模型、维度（如适用）与密钥脱敏状态
  - **管理员可编辑**：端点 / 模型 / 密钥（密码输入框，留空表示不修改）/ 向量维度
  - 「测试连接」按钮：对话模型发一次最小请求、向量化发一段测试文本
  - 保存后**立即生效**（重置服务单例，下一次请求即用新配置），无需重启
- **配置来源分层**：本地配置文件 `storage/api_config.json` > 环境变量 > 内置默认值
  - 文件只存用户通过界面填写的项；为空表示继续用环境变量
  - 「恢复为环境变量配置」按钮删除本地覆盖
- **安全边界**：
  - 界面**不回显**密钥明文，只显示脱敏片段；输入框类型为密码
  - 密钥不写日志、不进导出文件、不进入会话状态以外的展示区
  - 文件位于本机 `storage/`，加入 `.gitignore`
- **非管理员**：只读查看当前配置状态，不显示编辑控件

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `web-ui`：新增「项目说明页的 API 配置区块」要求（管理员可编辑、普通用户只读、测试连接、立即生效）
- `ai-enhancement`：「密钥管理」扩展配置来源（本地覆盖文件）与界面输入约束（不回显、密码框、仅管理员）

## Impact

**代码**

| 文件 | 改动 |
|---|---|
| `src/api_config.py` | 新增：本地覆盖文件的读写、字段白名单、脱敏、原子写 |
| `src/config.py` | 各配置 getter 支持「本地覆盖 > 环境变量 > 默认值」 |
| `src/ai_service.py` | 新增 `reset_service()`；`get_service` 支持配置变更后重建 |
| `src/ui/pages/about.py` | 新增「API 配置」区块（状态、编辑、测试、保存） |
| `tests/conftest.py` | 隔离 `ZHIGOU_API_CONFIG_PATH`，防止测试读到开发机真实密钥 |
| `.gitignore` | 忽略 `storage/api_config.json` |
| `.env.example` / `README.md` | 说明配置分层与界面修改方式 |

**测试**

- `tests/test_api_config.py`：读写、白名单、空值不覆盖、损坏文件回退、脱敏
- `tests/test_config.py`：覆盖优先级（文件 > 环境变量 > 默认）
- `tests/test_app.py`：管理员可见编辑控件、普通用户只读、密钥不回显、保存后生效

**风险**

- **本地文件存密钥**：与「只从环境变量读取」的旧约定不同，本变更将其扩展为「环境变量或本机覆盖文件」；文件在 `.gitignore` 中，界面与日志仍不回显。
- **测试误用真实密钥**：必须隔离配置路径（conftest），否则测试会联网并消耗额度。
- **模型/维度不匹配**：向量维度输入增加了校验；不匹配时提示，不写入。
