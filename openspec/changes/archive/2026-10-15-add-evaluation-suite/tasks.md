## 7. 首次运行发现的问题（本变更只记录，修复另开变更）

评测套件建成当天跑第一遍就找出三个真问题，**都不是评测集的问题，是系统的**：

- [x] 7.1 中文数字写在单位前认不出：「三千元以内的手机」解析不出预算。
  上下文词匹配要求词在数字**前**（「预算三千」可以），中文数字没有兜底路径
- [x] 7.2 两位阿拉伯数字认不出：「50 元以内的耳机」解析不出预算。
  兜底正则要求 `\d{3,6}`（至少三位）
- [x] 7.3 **「两千五」被静默算成 2005**（2000+5）。README 声称这种口语省略式
  「识别不了、会退回追问」，实际给出了一个**错误的值**——不报错、不追问，
  按偏窄的预算筛选。这是三个里最严重的一个
- [x] 7.4 统计行的「预算内 N 件」用的是**截断后**的条数（`limit` 截到 6），
  与已修复的 over_budget 是同一类问题，当时漏了

这四条由后续变更修复；修复后需重新生成 `docs/eval-report.md`。
