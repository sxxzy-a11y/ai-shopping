# Proposal

## Why

消费者在网上买东西时，真正缺的不是商品列表，而是「帮我判断哪件适合我」的能力。现有电商平台的推荐排序服从于广告曝光和利润，而不是用户的实际预算与用途；通用的聊天机器人又容易编造价格、参数和用户评价。大学生群体预算敏感、决策经验少，受这种信息不对称的影响最直接。

本项目要交付一个**基于大模型的智能消费决策助手「智购参谋」**：把「说出需求 → 筛选候选 → 比较分析 → 给出有依据的推荐 → 保存决策记录」这条完整链路做通，且**所有事实性结论都来自明确的商品数据，而不是模型想象力**。

现在做的理由：第一版用本地模拟数据就能把产品逻辑和交互完整验证出来，不受第三方接口、反爬和合规限制；等逻辑跑通后，替换数据源即可接入真实商品库。

## What Changes

- 新增 `zhigou-assistant` 应用（Streamlit 单体应用 + 分层 Python 业务模块），可在 Windows 本地一键启动
- 新增自然语言需求解析：把「预算 3000、主要写代码、偶尔打游戏、别太重」转成结构化的消费需求对象（商品类别、预算、使用场景、核心需求、可妥协项、品牌偏好、硬性限制）
- 新增商品数据层：**≥20 条**差异化模拟商品（笔记本 / 手机 / 耳机 / 键盘），存于独立 `data/products.json`，每条带明确的「演示数据」来源标注与更新时间
- 新增推荐引擎：预算硬过滤 + 多维度加权评分 + 面向需求的排序，**不按价格排序**；超预算商品显式标注而非伪装预算内
- 新增多商品比较：≥3 件商品横向对比价格、核心参数、适用场景、优缺点、预算匹配度
- 新增消费决策报告：需求摘要、筛选条件、推荐排序、推荐理由、优缺点、预算匹配、待核实项、最终建议；支持导出 Markdown / CSV
- 新增 SQLite 历史层：保存分析记录、需求摘要、推荐结果、时间戳、用户收藏
- 新增可选 AI 增强层：封装独立模块，密钥走环境变量，**无密钥时本地规则模式完整可用**，API 失败/超时时优雅降级而非崩溃
- 新增统一异常处理：输入为空/非法预算/数据文件缺失/无匹配商品/历史读取失败等场景均给出中文友好提示，不向前端暴露堆栈
- 新增 pytest 测试套件：不联网、不需要任何密钥即可全绿

### 明确不做（第一版范围外）

- 不接入真实电商平台的实时价格、库存或销量数据
- 不做用户账号体系、登录鉴权、多用户隔离
- 不做支付、下单、购物车等交易链路
- 不做爬虫
- 不引入微服务 / Kubernetes / 前后端分离架构

## Capabilities

### New Capabilities

- `demand-parsing`: 把中文自然语言购买需求解析为结构化消费需求对象，并在关键字段缺失时提出定向追问
- `product-catalog`: 本地模拟商品数据的结构定义、加载、校验与缺数据容错，含演示数据溯源标注
- `recommendation-engine`: 预算过滤、多维度可解释评分、权重集中配置、面向需求的排序与无结果时的放宽建议
- `product-comparison`: 多商品（≥3）横向比较的字段组装与差异高亮
- `decision-report`: 决策报告的内容组织、Markdown/CSV 导出与再打开
- `history-store`: SQLite 分析历史与用户偏好的持久化、读取与损坏容错
- `ai-enhancement`: 可选大模型接入（需求理解 + 推荐解释）、密钥管理、超时与失败降级
- `web-ui`: Streamlit 五个页面的用户可见行为、表单校验反馈与视觉规范

### Modified Capabilities

无。这是一个全新仓库，不存在需要修改的既有能力。

## Impact

**新增代码**
- `app.py`（Streamlit 入口，仅编排不承载业务逻辑）
- `src/`：`config.py`、`data_loader.py`、`demand_parser.py`、`recommender.py`、`scoring.py`、`comparison.py`、`ai_service.py`、`database.py`、`report_service.py`、`errors.py`
- `data/products.json`：≥20 条模拟商品
- `tests/`：覆盖筛选取值、排序、缺参容错、无匹配、比较、数据库读写、无密钥运行、API 降级
- `.streamlit/config.toml`（主题）、`requirements.txt`、`.env.example`、`.gitignore`、`README.md`

**新增依赖**
- 运行时：`streamlit`、`pandas`、`pydantic`（均已在本机安装）
- 开发期：`pytest`（已安装）
- 大模型调用：优先使用已安装的 `httpx` 直连，**不新增 SDK 依赖**；若后续确认需要 `openai` / `anthropic` SDK，单独提出

**平台与兼容性**
- 目标平台：Windows（开发机 Python 3.13.9 / Anaconda），同时兼容 macOS / Linux
- Streamlit 自定义样式须避免依赖不稳定的内部 DOM 结构与版本专有类名

**安全与合规**
- 密钥仅从环境变量读取，不写入源码、前端、日志、`st.session_state` 展示或仓库
- 模拟数据必须逐条标注为演示数据，不得冒充真实在售商品、真实评价或实时价格
- 评分必须命名为「系统匹配评分 / 需求适配评分」，不得暗示为真实市场口碑
- 调用外部 API 前，界面须说明将要发送的数据内容

**对既有系统无影响** —— 全新仓库，无外部调用方。
