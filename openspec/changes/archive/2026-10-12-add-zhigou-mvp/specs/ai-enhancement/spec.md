## ADDED Requirements

### Requirement: 两种运行模式

系统 SHALL 提供本地演示模式与 AI 增强模式。本地演示模式 SHALL 在不需要任何 API 密钥的情况下完成商品筛选、规则评分、商品比较与基础推荐。AI 增强模式 SHALL 在配置了合法可用的大模型 API 后提供自然语言需求理解与更丰富的推荐解释。

#### Scenario: 无密钥时本地模式完整可用

- **WHEN** 环境中未配置任何 API 密钥，用户提交需求
- **THEN** 系统完成解析、筛选、评分、排序与报告生成，界面明确标注当前运行在本地演示模式

#### Scenario: 配置密钥后启用 AI 增强

- **WHEN** 环境中配置了可用的 API 密钥与模型名
- **THEN** 系统使用大模型完成需求理解与推荐解释，界面标注当前运行在 AI 增强模式

#### Scenario: 模式状态对用户可见

- **WHEN** 用户查看界面
- **THEN** 界面明确显示当前处于本地演示模式或 AI 增强模式，以及当前使用的模型名称或本地规则说明

### Requirement: 密钥管理

系统 SHALL 从环境变量读取大模型 API 密钥。系统 SHALL NOT 将密钥硬编码在源码中，SHALL NOT 将密钥写入前端页面、日志、导出文件或会话状态展示区。

#### Scenario: 密钥未配置时提前报错

- **WHEN** 用户显式选择 AI 增强模式但未配置密钥
- **THEN** 系统在发起任何网络请求之前提示缺少哪个环境变量，并建议切换到本地演示模式

#### Scenario: 日志不泄露密钥

- **WHEN** 检查应用运行日志与异常信息
- **THEN** 日志中不出现密钥明文，涉及密钥的输出均已脱敏

#### Scenario: 界面不回显密钥

- **WHEN** 用户查看设置页或任何调试信息区域
- **THEN** 已配置的密钥仅显示为已配置状态与脱敏片段，不显示完整明文

### Requirement: 调用失败与超时降级

当大模型 API 不可用、超时、鉴权失败或返回内容无法解析时，系统 SHALL 自动降级到本地规则模式完成本次分析，并告知用户已发生降级及原因。系统 SHALL NOT 因 API 异常导致应用崩溃或分析中断。

#### Scenario: 网络超时触发降级

- **WHEN** AI 增强模式下模型服务在配置的超时时间内未响应
- **THEN** 系统在本地规则模式下完成本次分析，界面提示 AI 服务超时已降级，结果仍然可用

#### Scenario: 返回内容非法触发降级

- **WHEN** 模型返回的内容无法解析为预期的结构化结果
- **THEN** 系统回退到本地规则解析，界面标注该次解析由本地规则完成

#### Scenario: 鉴权失败给出明确原因

- **WHEN** 大模型 API 返回鉴权失败错误
- **THEN** 系统提示密钥无效或已过期，并继续以本地模式完成分析，不展示原始响应中的敏感信息

### Requirement: AI 输出不得编造事实

AI 增强模式下的分析结果 SHALL 基于传入的商品数据生成。当数据不足以支撑某项结论时，AI 输出 SHALL 明确表示信息不足并说明需要核实的内容，SHALL NOT 编造价格、配置、销量或用户评价。

#### Scenario: 缺失参数时声明信息不足

- **WHEN** 传入的商品数据中缺少某项参数，而用户需求涉及该参数
- **THEN** AI 输出说明该参数在现有数据中缺失，建议用户核实，不给出具体数值

#### Scenario: 输出被限制在传入数据范围内

- **WHEN** 检查 AI 生成的推荐理由
- **THEN** 其中引用的价格与参数均可在传入的商品数据中找到对应字段

#### Scenario: 模型不可用时结果仍可解释

- **WHEN** 降级到本地规则模式
- **THEN** 页面仍展示评分构成、加分项与扣分项，不因缺少 AI 解释而出现空白结果区

### Requirement: 模型调用封装

大模型调用 SHALL 封装在独立模块中，界面与业务逻辑 SHALL NOT 直接包含 HTTP 请求代码。

#### Scenario: 调用逻辑集中

- **WHEN** 检查业务模块与页面代码
- **THEN** 页面与推荐、比较、报告模块中不出现直接构造模型请求的代码，模型调用统一经独立服务模块完成

#### Scenario: 可替换模型端点

- **WHEN** 用户通过环境变量更换模型名或服务端点
- **THEN** 无需修改业务代码即可切换，切换后分析流程仍可正常完成
