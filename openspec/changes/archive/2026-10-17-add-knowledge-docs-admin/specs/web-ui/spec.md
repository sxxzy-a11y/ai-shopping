## MODIFIED Requirements

### Requirement: 知识库管理页

系统 SHALL 为管理员提供知识库管理页，包含：

- **商品知识库**：资料列表（标题、类型、切片数、已向量化、来源、更新时间、状态）；「＋ 新增资料」入口；支持删除文件型资料（二次确认）
- **生成全部向量**：显示待生成数量、执行进度与失败原因；未配置向量服务时说明如何配置
- **商品知识切片**：切片列表（资料、类型、序号、片段标题、字符数、状态）与筛选；可查看切片正文
- **检索调试**：输入问题后展示命中的切片、相似度分数与来源；未命中时明确说明

商品级资料 SHALL 标注「自动生成」，SHALL NOT 提供删除操作。

#### Scenario: 新增资料后出现在列表

- **WHEN** 管理员新增一份服务级资料
- **THEN** 商品知识库列表出现该资料，并提示可重新生成向量

#### Scenario: 删除资料需要确认

- **WHEN** 管理员未勾选「确认删除」
- **THEN** 删除按钮不可用或删除被拒绝

#### Scenario: 商品级资料不可删除

- **WHEN** 管理员展开一份商品级资料
- **THEN** 页面说明它由商品数据自动生成，不提供删除入口
