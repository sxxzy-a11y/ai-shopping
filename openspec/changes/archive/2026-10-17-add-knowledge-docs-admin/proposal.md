## Why

知识库目前只能通过编辑 `data/knowledge/` 下的 Markdown 文件维护，管理页只能查看。产品化的知识库后台需要能**新增资料**与**删除资料**——例如补一篇新的选购指南、删掉过时的 FAQ，而不必回到文件系统。

## What Changes

- **新增资料**（仅管理员）：
  - 表单：标题、知识类型（品类级 / 服务级）、分类（品类级必填）、来源、正文
  - 写入 `data/knowledge/custom/<slug>.md`，带完整 front-matter
  - 校验：标题与正文必填；品类级必须选分类且该分类未已有指南（避免同一分类两份指南互相打架）；文件名自动去重
- **删除资料**（仅管理员）：
  - 只能删除**文件型资料**（品类级 / 服务级）；商品级资料由商品字段自动合成，不提供删除，提示去商品维护编辑
  - 二次确认（勾选「确认删除」后才可点）
  - 删除后目录 mtime 变化，关键词索引自动重建
- **管理页**：商品知识库标签页增加「＋ 新增资料」入口与删除操作；商品级资料标注「自动生成」。

## Capabilities

### Modified Capabilities

- `knowledge-base`：新增「知识文档的增删」要求（校验、落盘位置、商品级不可删）
- `web-ui`：「知识库管理页」增加新增与删除资料的操作场景

## Impact

**代码**

| 文件 | 改动 |
|---|---|
| `src/knowledge/admin.py` | 新增：新增/删除文档、slug 去重、校验 |
| `src/knowledge/corpus.py` | `Document` 增加 `source_path`（删除时需要定位文件） |
| `src/ui/pages/knowledge_admin.py` | 新增资料表单、删除资料操作 |
| `tests/test_knowledge_docs_admin.py` | 新增后端测试 |
| `tests/test_app.py` | 界面增删测试 |

**风险**

- **误删**：只允许删除文件型资料，且需二次确认；商品级不可删。
- **同分类重复指南**：新增时拒绝与既有品类指南同分类的文档。
- **向量索引不同步**：新增/删除后关键词索引自动更新；语义检索需重新生成向量（界面提示）。
