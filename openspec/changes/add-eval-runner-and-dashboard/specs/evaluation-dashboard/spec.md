## ADDED Requirements

### Requirement: 效果评测页面的访问与数据来源

系统 SHALL 提供管理员专属的「效果评测」页面。页面 MUST 在入口执行管理员权限校验，SHALL NOT 仅依赖导航项隐藏来限制访问。

页面 SHALL 只读取已生成的评测报告文件，SHALL NOT 在页面渲染时执行评测、启动推荐链路或写入评测结果——评测是耗时操作，页面重跑不应触发它。

报告文件缺失时，页面 MUST 展示空状态，并给出可复制的生成命令；SHALL NOT 展示空白指标、零值或占位数字冒充评测结果。

#### Scenario: 管理员查看评测页

- **WHEN** 管理员打开「效果评测」页且报告存在
- **THEN** 页面展示该报告的总览、指标、分类结果与失败明细

#### Scenario: 非管理员无法访问

- **WHEN** 普通用户尝试访问「效果评测」页
- **THEN** 页面执行管理员校验并拒绝访问，导航中也不显示该入口

#### Scenario: 报告缺失

- **WHEN** 报告文件不存在
- **THEN** 页面显示空状态与生成命令，不显示任何评测数字

#### Scenario: 页面不执行评测

- **WHEN** 打开或重新运行「效果评测」页
- **THEN** 页面只读取报告文件，不调用评测 runner，不启动推荐或检索链路

### Requirement: 评测结论的如实展示

页面 SHALL 展示报告生成时间、评测集版本、用例总数、通过数、失败数、自动指标、分类通过情况、失败明细与检索模式。

页面 MUST 在显著位置声明评测集由本项目自建并标注，结论只在所声明口径下成立，是自评而非第三方基准。

页面 SHALL NOT 展示综合总分。需人工复核的指标 MUST 标注为「尚未测量」并列出复核材料，SHALL NOT 由页面推算或补全。

检索模式 MUST 按报告中记录的实际模式展示；报告未记录时 MUST 标注为「未记录」，SHALL NOT 猜测为向量检索或混合检索。

#### Scenario: 展示总览与分类结果

- **WHEN** 报告存在且格式有效
- **THEN** 页面展示用例通过情况，并按场景类别列出通过与总数

#### Scenario: 展示失败明细

- **WHEN** 报告中有失败用例
- **THEN** 页面列出失败用例的类别、失败的检查项与说明

#### Scenario: 人工指标不显示推断值

- **WHEN** 报告中包含需人工复核的指标
- **THEN** 页面显示「尚未测量」及复核材料，不显示由页面计算的近似值

#### Scenario: 不展示综合总分

- **WHEN** 查看页面上的评测结论
- **THEN** 不存在把自动指标与人工指标合并后的单一分数

#### Scenario: 检索模式如实显示

- **WHEN** 报告记录了检索模式
- **THEN** 页面显示该模式；报告未记录时显示「未记录」，不推断

### Requirement: 指标口径与指标值同屏

页面展示每个自动指标时，MUST 同时展示它的定义与分母，使用户不必跳转文档即可理解数字的适用范围。

#### Scenario: 指标旁边有口径

- **WHEN** 查看任一自动指标
- **THEN** 该指标的定义与分母与数值出现在同一视图内

### Requirement: 过期、损坏与未知格式报告的处理

页面读取报告时 SHALL 校验 schema 版本，并重新计算当前评测集与商品数据的指纹与报告比对。

schema 版本无法识别时，页面 MUST 提示报告格式与当前版本不匹配并给出重新生成命令，SHALL NOT 按旧字段猜测渲染。

报告 JSON 损坏时，页面 MUST 显示中文提示，SHALL NOT 向用户暴露堆栈或文件路径。

输入指纹不一致时，页面 SHALL 提示「报告可能已过期」，并继续展示报告内容与其生成时间；SHALL NOT 把旧报告静默呈现为当前结论。

#### Scenario: 未知 schema 版本

- **WHEN** 报告的 schema 版本不属于当前支持的版本
- **THEN** 页面提示格式不匹配并给出生成命令，不展示部分指标

#### Scenario: 报告文件损坏

- **WHEN** 报告不是合法 JSON 或缺少必要字段
- **THEN** 页面显示中文错误提示，页面其余部分不崩溃

#### Scenario: 输入数据已变化

- **WHEN** 当前评测集或商品数据的指纹与报告记录不一致
- **THEN** 页面显示「报告可能已过期」及报告生成时间，同时仍展示报告内容
