# 设计系统与品牌规范

> 适用：Vue 版全部界面（`frontend/src`）。最后更新 2026-11-09（v2.15）。
> 实现入口：`frontend/src/styles/`（tokens / base / components / responsive / index）、
> `frontend/src/components/BrandMark.vue`（品牌标记）、`frontend/public/favicon.svg`。

## 1. 视觉定位

**账本编辑风（Ledger Editorial）**——把一个「帮你算清楚」的工具，做成像一份认真写的评估报告，
而不是又一个通用 SaaS 仪表盘。

| 维度 | 选择 | 理由 |
|---|---|---|
| 气质 | 克制、可信、有分析感 | 产品承诺是「不替你拍板，但把依据摊开」；界面不能像电商叫卖 |
| 对比 | 深墨侧栏 vs 暖米纸底 | 冷暖对比形成"封皮 / 内页"的层次，比纯白底更有记忆点 |
| 强调 | 单一铜橙，不做渐变霓虹 | 铜的联想是算筹、账目、精确；也避开"青+深色 / 紫蓝渐变"的常见 AI 配色 |
| 字体 | 标题宋体 + 正文黑体 | 宋体提供"文书/报告"的语境，黑体保证正文可读；不加载网络字体，离线可用 |
| 装饰 | 账页横线纹理、装订边细线 | 装饰承载语义（这是账本），不是无意义的火花线 |

明确不做的：玻璃拟态、发光边框、渐变文字、hero 大标题居中堆叠、所有区块都做成卡片。

## 2. Logo 三个方向

三个方向都做了几何化处理，保证 16px favicon 下仍可辨认。

### 方向 A：算筹

三条来自不同方向的线，汇聚到一个暖色圆点，下方一条基准线。

- **理念**：产品做的事就是把多个维度（预算、用途、参数）收敛成一个结论，且结论有据可依。
  竖笔取「算筹」意象，基准线是账本底线。
- **配色**：深墨 `#14242b` 底 + 米白 `#f2e8d8` 线 + 铜橙 `#c8763f` 结论点。
- **适用场景**：中文语境品牌、需要文化辨识度的场合；单色印刷、深色底镂空均可用。
- **取舍**：三条线在 16px 下仍有形状差异，不像单字母那样容易糊；代价是需要两种变体
  （浅色底用实心块，深色底用镂空）。

### 方向 B：刻度棱镜（**已采用**）

外套一段不闭合的弧，内部一条上升折线穿过，代表"把需求拆成可比较的维度再打分"。

- **理念**：可解释的评分体系本身就是产品差异点，用"量具"的轮廓直接做成符号。
- **配色**：深墨 `#14242b` + 米白 `#f2e8d8` + 铜橙 `#c8763f`（沿用页面体系）。
- **适用场景**：偏数据工具、面向分析师的产品；中性、不挑行业。
- **取舍（已采用）**：刻度弧属分析类产品的常见符号，因此只保留**一段不闭合的弧**
  （不做整圈仪表盘、不单独画刻度线），让内部上升折线成为视觉主体，避免与"数据看板"撞脸。
  弧与折线在 16px 下轮廓仍可辨认，故此形态成立。

### 方向 C：双括号

一对不对称方括号夹住一个点，代表"把无数选择收敛到一个答案"。

- **理念**：极简符号化，强调"收敛"这个动作本身。
- **配色**：墨黑 + 珊瑚橙 `#df6742` + 米白。
- **适用场景**：国际化产品、需要极强符号记忆度的场合；favicon 表现最好。
- **取舍（未采用）**：中文品牌关联弱，脱离文字后看不出"参谋"的含义；也与现有暖米/深墨体系
  的"账本"气质不搭。

**采用 B 的理由**：产品的差异点就是"可解释的评分与比较"，开弧的轮廓把"可测量"讲明白，
内部上升折线给出"从多维数据到一个结论"的动势；配色沿用既有深墨 + 铜橙体系，
不另起一套色板。图元只有弧、1 条折线、1 个点，38px 侧栏与 16px favicon 均成立。

### 使用规范

| 场景 | 用法 |
|---|---|
| 深色背景（侧栏） | `<BrandMark tone="dark" />`：镂空，米线 + 铜点 |
| 浅色背景（登录页、启动屏） | `<BrandMark tone="light" />`：自带深墨圆角底 |
| favicon | `public/favicon.svg`，与 light 变体同构 |
| 最小尺寸 | 20px（再小只保留弧与折线的轮廓） |
| 留白 | 标记四周至少留 0.25 倍边长的空白 |
| 禁止 | 拉伸变形、换非品牌色、加投影/描边、把弧补成闭合圆环、把折线改成下降趋势 |

## 3. 色彩体系

全部定义在 `styles/tokens.css` 的 `:root`，组件只引用变量。

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg` | `#f5f1e9` | 页面底色（暖米纸） |
| `--surface` / `--surface-soft` | `#fffdf9` / `#faf6ee` | 卡片 / 次级区块 |
| `--ink` / `--ink-soft` / `--muted` | `#17262c` / `#4a5d64` / `#84939a` | 三级文字 |
| `--sidebar` / `--sidebar-soft` | `#14242b` / `#1c3138` | 侧栏底色 / 悬浮态 |
| `--accent` / `--accent-dark` / `--accent-soft` | `#c8763f` / `#a85f2e` / `#fbf1e7` | 铜橙强调三档 |
| `--amber` / `--green` | `#c99a45` / `#3d7f66` | 警告 / 通过 |
| `--line` | `#e6dfd2` | 分隔线、边框 |

对比度：`--ink` 对 `--surface` ≈ 13:1，`--ink-soft` 对 `--surface` ≈ 7:1，`--muted` 仅用于
辅助说明（对白底 ≈ 3.4:1，不用于关键正文）；铜橙按钮上的文字用 `#fffdf9`，对比度 ≈ 3.6:1，
字号 ≥14px 且加粗，符合大文本 AA。

## 4. 字体体系

| 角色 | 字体栈 | 用法 |
|---|---|---|
| 正文 | `--font-body`：PingFang SC / Microsoft YaHei / system-ui | 全部正文、表单、表格 |
| 标题 | `--font-display`：Songti SC / STSong / Noto Serif SC / SimSun / Georgia | `h1`、hero 标题、登录页标题、品类大标题 |
| 数字 | 正文栈 + `font-variant-numeric: tabular-nums` | 统计值、表格数字、价格 |

字号阶梯：`h1` 28px（移动 22–24）、hero 34px（移动 22–26）、`h2` 16px、正文 14px、
辅助 12–13px、eyebrow 10.5px + 3px 字距。不使用 `clamp()` 是因为断点差异已经用媒体查询处理，
避免两套缩放叠加。

**注意**：标题只用宋体、且只在大字号（≥22px）使用；正文与小标题一律黑体，避免 Windows 上
SimSun 小字号发虚。

## 5. 空间与形状

- 间距基数是 4px，常用 8 / 12 / 16 / 20 / 24 / 34。
- 圆角：卡片 16px、按钮/输入 10px、标签 999px；移动端卡片降为 14px。
- 阴影只做两级：`--shadow`（常态）与 `--shadow-lift`（浮起）。都在底部大范围低透明度，
  不做"四周均匀发光"。
- 卡片不再全局加 hover 抬升，只有可点击卡片才给 `border-color` 变化，避免整页抖动。

## 6. 组件规范

| 组件 | 规范 |
|---|---|
| 主按钮 | 实心铜橙 + 顶部 1px 内高光，无外投影；hover 加深，active 下移 1px |
| 次按钮 | 白底 + 细边框，hover 边框与文字变铜橙 |
| 徽标 | 999px 胶囊，四种语义色（中性 / 铜橙 / 绿 / 琥珀），文字 11px |
| 卡片 | 1px 边框 + 低阴影，内边距 24px（移动 18px） |
| 统计块 | 左侧 2px 竖线作为"账目"暗示，强调项用铜橙 |
| 表格 | 表头 11.5px + 字距，行 hover 淡米色，最后一行去下边框 |
| 提示 | 左 3px 色条 + 浅底，不用整块彩色 |
| 空态 | 居中，标题 + 一句可执行的下一步，不放大图标 |
| 导航激活 | 左侧 3px 铜橙竖条 + 淡铜底；移动端改为底部 16px 横条 |

## 7. 动效

- 统一缓动 `--ease: cubic-bezier(.22, 1, .36, 1)`（指数收尾，不回弹）。
- 只动 `background / color / border-color / transform / opacity`，不动布局属性。
- 时长 120–180ms；`prefers-reduced-motion: reduce` 下全部降到 0.001ms。
- 加载态用 15px 旋转环，不做骨架屏闪烁。

## 8. 响应式

| 断点 | 变化 |
|---|---|
| ≥ 901px | 244px 固定侧栏；页面内容最大 1180px 居中 |
| ≤ 900px | 侧栏转为顶部横向条；三组导航**拍平成一行**横向滚动（隐藏滚动条 + 右侧渐隐）；`grid-2/3` 变单列；hero 34→26px |
| ≤ 560px | 卡片内边距 18px、圆角 14px；hero 22px；隐藏顶栏的参考价 chip；按钮与导航的最小触控高度 40px |

移动端导航拍平是这次的关键修复：原先三组各占一行，390px 宽度下要吃掉约 250px 首屏高度，
且「AI 问答」被截断。

## 9. 可访问性

- 全局 `:focus-visible` 2px 铜橙描边 + 3px 偏移，键盘可见。
- 触控目标 ≥ 40px（≤560px 断点）。
- 图标均为内联 SVG（`AppIcon`），不依赖 emoji；品牌标记带 `role="img"` 与 `aria-label`。
- 状态不只用颜色表达：徽标有文字、提示有左侧色条 + 文案。

## 10. 落地文件

| 文件 | 内容 |
|---|---|
| `frontend/src/styles/tokens.css` | 设计令牌与全局 reset |
| `frontend/src/styles/base.css` | 登录、表单、按钮、应用骨架、路由反馈 |
| `frontend/src/styles/components.css` | 卡片、表格、徽标、提示等业务组件 |
| `frontend/src/styles/responsive.css` | 全部断点与 reduced-motion |
| `frontend/src/styles/index.css` | 汇总入口，`main.ts` 只引用它 |
| `frontend/src/components/BrandMark.vue` | 品牌标记组件 |
| `frontend/public/favicon.svg` | 标签页图标 |
| `frontend/src/components/AppShell.vue` | 侧栏 Logo、导航容器 `.nav-scroll`、路由预加载与淡入 |
| `frontend/src/views/LoginView.vue` | 登录页品牌区与装订边细线 |
| `frontend/src/App.vue` | 启动屏品牌标、会话失效出口、顶部进度条 |

后续新增页面时：只用 `styles/` 里的类和令牌，不内联颜色；标题用 `h1/h2` 语义标签，
字号交给全局样式，不要逐页覆盖。新增样式放进对应的四层之一，不新开散文件。
